## 路由實測：三網繞美，中轉是標配

這台的短板在線路，不在硬件。實測結果是：三網去程全部經美國中轉，回程電信和聯通也走美國，移動回程在上海、廣州方向表現尚可，北京方向同樣繞美。整體網路速度要好看，得自己配中轉。

這意味著什麼：從大陸直接連，延遲不會是香港機房該有的水準，晚高峰更明顯。解決方式有兩條，一是用香港或日本節點做中轉，二是掛上 BBR。BBR 能改善擁塞時的吞吐，但改變不了物理路徑繞美這件事，它只是緩解。

如果你手上已經有中轉節點，或者主要用戶本來就不在大陸，這條線路的問題就不存在，剩下的全是優點：便宜、頻寬大、不限流量、能換機房。

## 常見問題

**香港 VPS 需要備案嗎？**
不需要。香港不在大陸監管範圍內，網站直接上線。

**200Mbps 是獨享還是共享？**
共享。宿主机給 10Gbps 接入，分配到每台 VPS 的上限是 200Mbps，實際速度取決於同宿主机其他用戶的用量。

**標示不限流量，會不會限速？**
官方標示是不限流量。實際體驗和共享頻寬、鄰居用量有關，這點任何不限流量的機器都一樣。

**能裝 Windows 嗎？**
現有資料沒有提到 JustHost 香港機房的 Windows 支援情況，需要就直接問客服，別預設可以。

**買了發現延遲不行怎麼辦？**
先確認是不是沒掛中轉。三網繞美是已知特性，不是故障。中轉之後仍然不行，再走退款流程。
